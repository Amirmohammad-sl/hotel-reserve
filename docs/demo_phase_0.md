# سناریوی ارائه و دمو فاز ۰ (Demo Script — Phase 0)
- زمان تخمینی: ۵ الی ۸ دقیقه
- مخاطب: استاد و دستیاران آموزشی درس برنامه‌نویسی وب

---

## بخش ۱: مدیریت مخزن، CI و هسته بک‌اند (ارائه‌دهنده: امیرمحمد سلیمانی — اپراتور A)

1. **مدیریت مخزن و فرآیند دونفره (۲ دقیقه):**
   - نمایش ساختار مخزن در گیت‌هاب: [hotel-reserve](https://github.com/Amirmohammad-sl/hotel-reserve)
   - نمایش قوانین محافظت از شاخه `main` (Branch Protection):
     - عدم امکان پوش مستقیم به `main`.
     - اجباری بودن ثبت Pull Request و حداقل ۱ تأیید (Review Approve) توسط هم‌تیمی.
     - اجباری بودن سبز شدن تست‌های خودکار CI (`backend` و `frontend`).
   - نمایش تاریخچه پول‌ریکوئست‌های ادغام‌شده برای فاز ۰ (PR #1 تا PR #5).

2. **راه‌اندازی و بررسی بک‌اند جنگو (۲ دقیقه):**
   - اجرای تست‌های خودکار بک‌اند:
     ```bash
     cd backend
     python manage.py test apps
     ```
   - اجرای سرور توسعه جنگو:
     ```bash
     python manage.py runserver
     ```
   - باز کردن اندپوینت تست سلامت در مرورگر یا با curl:
     `http://localhost:8000/api/health/`
     خروجی دریافتی: `{"data": {"status": "ok"}}`
   - توضیح کوتاه ساختار دیتابیس PostgreSQL و مدل سفارشی کاربر (`accounts.User` ارث‌بری‌شده از `AbstractUser`).

## بخش ۲: فرانت‌اند React، تست یکپارچگی و هماهنگی (ارائه‌دهنده: مهدی مرادی — اپراتور B)

3. **راه‌اندازی فرانت‌اند و بررسی رابط کاربری (۲ دقیقه):**
   - اجرای سرور توسعه Vite:
     ```bash
     cd frontend
     npm run dev
     ```
   - باز کردن آدرس `http://localhost:5173/` در مرورگر.
   - نمایش راست‌چین بودن کامل صفحه (RTL) و بارگذاری آفلاین فونت وزیرمتن (`@fontsource/vazirmatn`).
   - بررسی کامپوننت وضعیت اتصال (HealthBadge):
     - نشان دادن بج سبز رنگ **«بک‌اند آنلاین است (ok)»**.
     - توضیح ارسال درخواست از فرانت‌اند به مسیر `/api/health/` از طریق ریورس‌پروکسی داخلی Vite به بک‌اند جنگو.

4. **تست رفتار واکنشی و سناریوی قطعی سرور (۱ دقیقه):**
   - متوقف کردن موقت سرور جنگو در ترمینال بک‌اند (`Ctrl+C`).
   - کلیک بر روی دکمه «تلاش مجدد» در فرانت‌اند و مشاهده تغییر بج به رنگ قرمز **«بک‌اند در دسترس نیست»**.
   - راه‌اندازی مجدد جنگو و کلیک بر روی «تلاش مجدد» جهت بازگشت به حالت آنلاین سبز.

5. **هماهنگی با استاد و بورد وظایف (۱ دقیقه):**
   - اجرای اسکریپت مدیریت وظایف پروژه:
     ```bash
     python scripts/board.py --summary
     ```
     نمایش پیشرفت فاز ۰ (۶ از ۶ تسک — ۱۰۰٪).
   - توضیح ایمیل ارسال‌شده به استاد درس (`nedasoltanih@gmail.com`)، مهلت پاسخ ۷ روزه و تشریح استراتژی پشتیبان (Plan B).
