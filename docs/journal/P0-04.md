## What was done (3–6 bullets)
- Scaffolded frontend application using Vite with React (plain JavaScript, no TypeScript) and modern ESLint setup.

- Configured Vite development server proxy (`/api` → `http://localhost:8000`) for seamless local full-stack development without CORS issues.
- Built reusable layout (`Navbar`, `Footer`) and placeholder routes (`/`, `/hotels`, `/login`, `/register`, `/manager`, 404).

## Why / design decisions (and alternatives rejected)
- **Plain JavaScript over TypeScript**: Per project convention (D-001 / `03-frontend-react.md`), JS keeps the frontend simpler and directly aligned with the course scope while preventing unnecessary build complexities.
- **Vite Proxy over CORS configuration**: Routing `/api` requests through Vite's dev proxy ensures that cookies (`sessionid` and `csrftoken`) behave as genuine first-party `same-origin` cookies in development, exactly matching production deployment where Django serves or reverse-proxies the SPA.
- **Offline `@fontsource/vazirmatn` over Google Fonts/CDN**: Ensures the application and typography load flawlessly in offline or restricted intranet environments.
- **Tailwind CSS v4 with logical properties**: Using modern `@tailwindcss/vite` and RTL logical utility classes (`ms-`, `me-`, `ps-`, `pe-`, `text-start`) provides a clean and standard Persian UI without needing custom direction-override plugins.

## How it works (follow ONE request/click end to end)
- When the user visits `http://localhost:5173/`, Vite serves `index.html`. React mounts `App.jsx`, which renders `Layout` and `HomePage`.
- Inside `HomePage`, the `HealthBadge` component mounts and executes `getHealth()`.
- `getHealth()` calls `apiClient.get('/api/health/')`. Vite's dev server intercepts `/api/health/` and forwards it to `http://localhost:8000/api/health/` on the Django backend.
- Django handles the request and responds with `{"data": {"status": "ok"}}`.
- `apiClient` verifies `response.ok`, extracts `data`, and returns `{ status: "ok" }`.
- `HealthBadge` updates its state to `online` and displays a green badge: `بک‌اند آنلاین است (ok)`.

## Gotchas / things that surprised us
- In modern ESLint with `eslint-plugin-react-hooks`, invoking an async state-setting function synchronously inside `useEffect` triggers the `react-hooks/set-state-in-effect` rule. Refactoring to an async promise chain with an active boolean cleanup pattern resolves this and prevents memory leaks when components unmount.
- Tailwind v4 uses the `@tailwindcss/vite` plugin instead of `postcss.config.js` and `tailwind.config.js`, streamlining the build pipeline and reducing configuration boilerplate.

## Viva Q&A (Persian, 3–5) — questions the professor could ask about this task
1. س: چرا به جای فراخوانی مستقیم `fetch` در کامپوننت‌ها از یک لایه کلاینت مرکزی در `src/api/client.js` استفاده کردیم؟
   ج: متمرکز کردن درخواست‌ها در یک لایه مرکزی امکان افزودن خودکار هدر `X-CSRFToken`، تنظیم `credentials: 'same-origin'`، هندل کردن فرمت استاندارد پاسخ‌ها (`{"data": ...}`) و تبدیل خطاهای سرور به ساختار یکدست را در کل برنامه فراهم می‌کند و از تکرار کد و خطاهای امنیتی جلوگیری می‌کند.
2. س: مکانیزم ارسال توکن CSRF در درخواست‌های ایجکسی فرانت‌اند به جنگو چگونه کار می‌کند؟
   ج: جنگو هنگام درخواست‌های اولیه کوکی‌ای به نام `csrftoken` تنظیم می‌کند. کلاینت ما در متدهای تغییردهنده (POST, PUT, DELETE) مقدار این کوکی را از `document.cookie` خوانده و در هدر `X-CSRFToken` به بک‌اند ارسال می‌کند تا از حملات CSRF محافظت شود.
3. س: پروکسی Vite چه مشکلی را در محیط توسعه (Development) حل می‌کند؟
   ج: در محیط لوکال، فرانت‌اند روی پورت ۵۱۷۳ و جنگو روی پورت ۸۰۰۰ اجرا می‌شوند. ارسال مستقیم درخواست باعث ایجاد خطای CORS و عدم تبادل امن کوکی‌های سشن می‌شد. با تنظیم پروکسی در `vite.config.js`، مرورگر تمام درخواست‌ها را به همان مبدا لوکال فرانت‌اند ارسال کرده و سرور توسعه Vite آن را بدون مشکل CORS به جنگو فوروارد می‌کند.
4. س: چرا از فونت محلی Vazirmatn به جای لینک‌های خارجی CDN استفاده شد؟
   ج: وابستگی به CDNهای خارجی ممکن است به دلیل قطعی اینترنت، فیلترینگ یا مشکلات شبکه مختل شود. با نصب پکیج `@fontsource/vazirmatn`، فونت‌ها به همراه باندل پروژه بارگذاری شده و سایت کاملاً آفلاین و ایزوله کار می‌کند.
