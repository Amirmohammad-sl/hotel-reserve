## Why / design decisions (and alternatives rejected)
- **Mermaid in Markdown**: Used GitHub-native Mermaid syntax so diagrams render automatically inside GitHub repository views and PR diffs without requiring external viewers.
- **Standalone SVG Exports**: Generated vector SVG files in `docs/report/diagrams/` so they can be embedded cleanly into LaTeX / PDF or HTML project reports without loss of resolution.
- **Course Rubric Alignment**: Explicitly included all core course items (manager room definition, free vs booked room monitoring, discount code validation, guest search, booking confirmation, reviews) to ensure full marks during professor evaluation.

## Gotchas / things that surprised us

1. س: دیاگرام‌های فرآیندی (Process Diagrams) چه نقشی در معماری نرم‌افزار و تحویل فازهای بعدی دارند؟
   ج: این دیاگرام‌ها جریان دقیق تبادل داده بین کاربر، کلاینت (React)، اندپوینت‌های جنگو و دیتابیس را پیش از کدنویسی مشخص می‌کنند. به این ترتیب هر دو اپراتور (A و B) توافق مشترکی در مورد امضای متدها، وضعیت‌های رزرو و نحوه هندل کردن خطاها (مانند 409 Conflict در اتمام ظرفیت) به دست می‌آورند.
2. س: در دیاگرام توالی رزرو اتاق، جلوگیری از رزرو تداخل‌دار (Overbooking) چگونه مدل‌سازی شده است؟
   ج: از طریق یک تراکنش اتمیک (`transaction.atomic`) و اجرای کوئری محاسبه همپوشانی بازه‌های زمانی رزروهای تایید شده (`confirmed`) با ظرفیت اسمی `RoomType`. اگر تعداد اتاق‌های آزاد کمتر از درخواست مهمان باشد، تراکنش Rollback شده و پاسخ 409 ارسال می‌شود.
3. س: دیاگرام مشاهده اتاق‌های آزاد و رزرو شده توسط مدیر چگونه نیازمندی صورت‌پروژه را برآورده می‌کند؟
   ج: مدیر با ارسال بازه تاریخی به اندپوینت `/api/manager/hotels/{id}/availability/`، لیستی ماتریسی به تفکیک هر روز اقامت دریافت می‌کند که در آن کل ظرفیت، اتاق‌های اشغال شده و اتاق‌های خالی محاسبه و نمایش داده می‌شود.
4. س: تفکیک نقش‌ها (Role-based access) چگونه در فرآیندهای accounts و views رعایت شده است؟
   ج: مدل User دارای فیلد `role` (با مقادیر `guest` و `manager`) است؛ میدل‌ور و دکوراتورهای دسترسی (`role_required`) در بک‌اند و گارد مسیرها در فرانت‌اند بررسی می‌کنند که تنها مدیران به تعریف هتل و گزارش‌های مدیریتی دسترسی داشته باشند و مهمانان عملیات رزرو و استعلام را انجام دهند.
