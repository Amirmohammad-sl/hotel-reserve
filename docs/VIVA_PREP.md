# VIVA PREP — بانک سوال برای جلسه تحویل (هر دو نفر باید جواب بدهند)

با `/viva-drill` تمرین کنید. بعد از هر تسک، سوال‌های journal را اضافه کنید.

## معماری
1. چرا React و Django را جدا کردید؟ Django کدام وظایف را دارد؟ (D-001)
2. احراز هویت چطور کار می‌کند؟ چرا JWT نگذاشتید؟ CSRF چیست و چطور از React ارسال می‌شود؟
3. Template در پروژه شما کجا استفاده شده؟
4. چرا از DRF استفاده نکردید؟

## مدل‌ها
5. روابط بین User، Hotel، RoomType، Booking، DiscountCode را توضیح دهید. هر `on_delete` را چرا انتخاب کردید؟
6. چرا Room جدا نداریم و `quantity` در RoomType است؟ مزیت و عیب؟
7. `CheckConstraint` ها چه چیزی را تضمین می‌کنند؟ ایندکس‌ها برای چیست؟
8. چرا User را سفارشی کردید و چرا قبل از اولین migrate؟

## Manager ها
9. هر Manager/QuerySet چیست، چرا تعریف شد، کجا استفاده می‌شود؟
10. `with_availability` چطور موجودی را حساب می‌کند؟ شرط همپوشانی چیست؟ ورود و خروج در یک روز؟
11. تفاوت Manager و QuerySet؟ `as_manager` چه می‌کند؟

## رزرو
12. اگر دو نفر همزمان آخرین اتاق را رزرو کنند چه می‌شود؟ (`atomic` و `select_for_update`)
13. کد تخفیف چه شرایطی دارد؟ `used_count` چه زمانی تغییر می‌کند؟
14. چرا quote جدا از create است؟

## Session / Cookie / Logging
15. Session کجا ذخیره می‌شود؟ فلگ‌های امنیتی کوکی چیست؟ remember-me چطور کار می‌کند؟
16. کوکی `last_city` را کجا ست و کجا می‌خوانید؟
17. سطح‌های لاگ و فایل‌های لاگ؟ چه چیزی هرگز لاگ نمی‌شود؟ middleware چه می‌کند؟

## Form / View
18. چرا هر ورودی با Django Form اعتبارسنجی می‌شود؟ نمونه یک Form را توضیح دهید.
19. تفاوت 401، 403، 404، 409 در پروژه شما؟ چرا برای هتل دیگران 404 می‌دهید؟
20. مسیر کامل «ثبت یک رزرو» از کلیک تا دیتابیس را بگویید (فایل‌ها را نشان دهید).

## ایمیل، تست، بهینه‌سازی
21. توکن تایید ایمیل چطور ساخته و اعتبارسنجی می‌شود؟
22. چه چیزهایی تست کرده‌اید؟ یک تست مهم را توضیح دهید.
23. `select_related` در برابر `prefetch_related`؟ مشکل N+1 را در پروژه خودتان نشان دهید.

## Git و کار تیمی
24. هر نفر چه تسک‌هایی انجام داد؟ یکی از PR های همتیمی را توضیح دهید.
25. چرا squash merge؟ چرا main محافظت شده؟ CI چه چیزی را چک می‌کند؟
